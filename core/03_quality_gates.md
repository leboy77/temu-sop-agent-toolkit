# 03 - Quality Gates

| Gate | 检查问题 | 通过条件 | 不通过时 |
| --- | --- | --- | --- |
| G0 选品 | 市场是否需要、版权和履约是否可行 | 业务负责人确认 | `BLOCKED`，不进入核价 |
| G1 核价 | 成本是否真实、价格是否算对 | 脚本通过且负责人批准 | 修改商品卡或价格，不生成上架包 |
| G2 素材 | 图片是否完整、对应正确、可商用 | 素材清单和授权齐全 | 退回素材生产 |
| G3 合规 | 市场资料和表述是否完整 | 合规负责人批准 | `BLOCKED`，不上架 |
| G4 发布 | 商品字段和批次是否一致 | 模板校验通过 | 不点击批量提交 |
| G5 发布结果 | 平台是否明确成功 | 商品可查询且状态正确 | `REVIEW_REQUIRED`，先查询 |
| G6 履约 | 订单、面单、渠道和库存是否正确 | 同国家/同渠道一致性通过 | 停止推单并转异常 |
| G7 复盘 | 指标是否有数据基础和基线 | 数据量达标且时间窗有效 | 标注数据不足，不输出结论 |

## 阻断原则

- 质量门只能由明确证据通过，不能因为“以前这样能过”而跳过。
- Agent 可以整理证据，但不能代替业务或合规负责人签字。
- 自动工具返回成功只代表操作完成，最终状态以平台列表或接口查询为准。
