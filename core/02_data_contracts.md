# 02 - Data Contracts

## 单一事实来源

| 数据 | 唯一来源 | 下游消费者 |
| --- | --- | --- |
| 市场仓库、时效、税务和平台规则 | `market_profile.json` | 定价、合规、履约 |
| 商品身份、供应商和规格 | `product_brief.json` | 素材、上架、履约 |
| 成本、费用、售价和利润线 | `price_sheet.csv` | 上架、活动、广告 |
| 合规材料和有效期 | `compliance_pack.md` 及其附件索引 | 发布、复核 |
| 图片与授权 | 商品卡中的素材清单 | 上架、广告 |
| 运行和异常 | 运行记录与 `exception_log.csv` | 复盘、审计 |

## 命名

- `market_id`：`eu-y2`、`us-y1-pod`。
- `product_brief_id`：由市场、时间和序号组成，如 `US-Y1-20261028-001`。
- `run_id`：每次执行独立生成，如 `RUN-20261028-153000-US-Y1-001`。
- `revision`：商品卡每次实质变更递增。

## 必填逻辑

发布前至少满足：

- 商品身份和类目明确；
- 供应商、采购价、重量和尺寸可追溯；
- 所有面向买家的参数来自最终规格表；
- 每个 SKU 有对应色值、尺码、价格和库存；
- 每张商用图片有来源或授权记录；
- 市场要求的税务、主体、标签和包装资料完整；
- 最终售价高于盈亏价，或有审批过的战略亏损记录。

## 敏感数据

以下字段只保存在私有运行环境：

- 真实后台账号、Token、API Key；
- 仓库完整地址、联系人、电话；
- 供应商合同价；
- 客户姓名、地址、订单号；
- 未脱敏的平台截图、SKU 和内部人员姓名。

仓库和示例中只使用占位值或脱敏数据。
