# 美国 Y1 每日运营

## 每日检查

- [ ] 昨日新品核价、发布和列表状态
- [ ] 今日活动、流量加速和广告异常
- [ ] 订单、面单、库存和物流异常
- [ ] 店铺处罚、合规弹窗和授权到期
- [ ] 退款、差评和质量问题

## 商品维护

- [ ] 确认货号唯一性，不沿用前一天数字前缀
- [ ] 检查商品、SKU、色值和图片映射
- [ ] 检查核价表版本与在售价格一致
- [ ] 核对活动模板是否对应最新价格
- [ ] 检查批量任务的成功与待确认数量

## 增长检查

- [ ] 记录活动、流量加速和广告基线
- [ ] 一次只验证一个主要改动
- [ ] 检查花费、订单、利润和售后
- [ ] 未达标时回诊断，不直接追加同一动作

## 售后

- [ ] 对退款和差评分型
- [ ] 区分描述误解、产品质量、物流和尺码问题
- [ ] 可修复问题回流到标题、图片或详情页
- [ ] 涉赔、删评或平台规则争议由人工处理
