# 美国 Y1 POD Playbook

## 适用范围

本 Playbook 覆盖美国 Y1 POD 的三仓配置、核价表、普通商品与 POD 两种业务模式、采集与裂变、AI 出图、商品模板、批量核价、活动、流量加速、广告和售后。

## 主流程

```text
三仓与运费模板
  -> 核价表
  -> 款式采集与筛选
  -> 先测试、后裂变
  -> AI/PS 素材
  -> SKU/模板
  -> 批量发布
  -> 核价/活动/流量
  -> 广告与售后
```

## 关键控制点

1. 核价表是运营中心，商品卡和上架价格必须引用同一版本。
2. 先验证数据表现，再做图案或款式裂变。
3. POD 与普通商品分别配置业务模式和模板，禁止混用。
4. 采集链接、商品款式和 SKU 数量必须核对，单 SKU 与多 SKU 分开处理。
5. 标题、图片和参数中的数字来自同一规格表。
6. 发布结果未知时先查列表，不重复提交。
