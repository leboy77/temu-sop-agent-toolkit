# 欧洲 Y2 每日运营

## 上班前

- [ ] 检查店铺告警、授权、库存和订单积压
- [ ] 查看昨日上新、核价和发布结果
- [ ] 检查是否有未关闭的合规或履约异常

## 上午

- [ ] 处理订单推送和 ERP 异常
- [ ] 核对核价表与在售价格
- [ ] 检查待处理商品和素材任务
- [ ] 处理活动、流量和广告告警

## 下午

- [ ] 第二次推单并确认面单
- [ ] 复查当日上架结果
- [ ] 处理售后和差评升级
- [ ] 更新异常记录

## 每周

- [ ] 抽查合规材料与标签一致性
- [ ] 抽查商品、SKU、色值和图片映射
- [ ] 复盘广告、流量和售后指标
- [ ] 清理重复模板、失效规则和过期授权

## 记录

每日目标、异常数和结果写入 `templates/daily_ops_log.md`。任何“数量、百分比、上架上限”都必须由市场配置提供，不直接写死在 Prompt 中。
