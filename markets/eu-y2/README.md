# 欧洲 Y2 Playbook

## 适用范围

本 Playbook 覆盖欧洲 Y2 的仓库配置、配送模板、VAT/欧代/制造商/包装合规、ERP 推单、面单、批量合规与活动工具，以及商品图片生产。

## 主流程

```text
店铺基础设置
  -> 仓库与配送区域
  -> 商品采集与规格整理
  -> VAT / 欧代 / 制造商 / 包装法
  -> SKU 与素材包
  -> ERP 订单/面单
  -> 合规与活动
  -> 每日核价、异常和售后
```

## 关键控制点

1. 仓库与运费模板必须有明确生效范围和启用日期。
2. 税务、合规主体、制造商和标签地址必须一致。
3. 订单推单与面单按国家分批执行，不混合不同国家的渠道。
4. 商品 SKU、颜色、尺码和工厂生产编码必须一一对应。
5. 批量合规模板首次建立后，在定价或产品信息变化时重新校验。
6. 每日核价、异常、广告和售后必须记录结果，不仅执行点击。
