# TASK - Category Precheck

目标：在投入完整价格带和竞品分析前，判断类目是否适合当前公司。

## 1. 货盘适配

| 检查项 | 结论 | 证据 |
| --- | --- | --- |
| 有现货或可确认交期 | ✅ / ❌ / ⚠️ | |
| 有稳定供应商 | ✅ / ❌ / ⚠️ | |
| 成本和最小起订量可接受 | ✅ / ❌ / ⚠️ | |
| 适合目标市场 | ✅ / ❌ / ⚠️ | |
| 仓储、重量和体积可承载 | ✅ / ❌ / ⚠️ | |
| 尺码、退货和售后可处理 | ✅ / ❌ / ⚠️ | |

三项以上明确不满足时输出 `precheck_pass=false`，停止后续市场分析。

## 2. 风险

逐项判断：

1. 是否易碎、易变形或运输风险高
2. 是否容易产生尺码或描述争议
3. 是否需要认证、检测或平台权限
4. 是否涉及商标、人物、图案或版权
5. 是否容易虚标材质、功能或参数
6. 是否能承受退货、退款和售后
7. 是否符合当前仓库和配送时效

## 3. 市场专项

欧洲 Y2：

- VAT 与税务主体
- 欧盟负责人
- 制造商与商品识别码
- 包装 EPR 和标签
- 多国家配送和语言

美国 Y1 POD：

- 图案和人物权利
- 图案在目标底色上的效果
- 尺码和版型
- 材质和洗护
- 美国制造商和标签
- 三仓配送

## 4. 结论

```yaml
precheck_pass: true
risk_level: low
blocking_items: []
pending_confirmations: []
next_step: market_analysis
```

结论必须写成：在哪些条件成立时继续，哪些条件不成立时应停止。
