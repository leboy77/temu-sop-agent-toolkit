# 04 - Listing

## 定位

把已批准的素材和商品信息映射到平台字段和批量模板。

## 输入

- 商品卡与价格表
- SKC/SPU、类目、属性和尺码表
- SKU、色值、图片和库存
- 市场配置与当前平台字段规则
- 上架批次定义

## 输出

- 单 SKU 或批量上架文件
- 字段映射表
- 发布前校验报告
- 发布任务与结果查询记录

## 发布流程

```text
选择模板 -> 导入商品 -> 映射字段 -> 校验 -> 人工确认
-> 小批量提交 -> 查询结果 -> 全量提交 -> 回列表校验
```

## 必查字段

- 商品身份和类目
- SKU 数量、颜色和尺码
- 标题、图片和视频数量
- 价格、库存和包装规格
- 制造商和合规字段
- 发货仓、配送模板和时效

## 错误处理

- 图片不足或超限：回到素材模块。
- 类目/属性错误：回到商品卡。
- 价格错误：回到核价表。
- 合规字段缺失：回到合规模块。
- 授权失效：停止批次。
- 发布结果未知：查询列表，不重复提交。
