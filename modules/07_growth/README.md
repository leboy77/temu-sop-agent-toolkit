# 07 - Growth

## 定位

在价格、库存和履约稳定的前提下，分析活动、流量加速和广告，输出有边界的动作建议。

## 输入

- 已审批商品和核价表
- 活动模板与有效期
- 流量加速状态
- 广告曝光、点击、加购、订单、花费和销售额
- 退货和售后
- 外部干扰事件

## 输出

- 数据质量结论
- 漏斗 diagnóstico
- 盈亏线 ROAS
- P0/P1/P2 动作
- 明确不改的字段
- 复测时间与指标

## 原则

- 数据不足时不下结论。
- 曝光、点击、加购、成交和利润按顺序诊断，不直接跳到调价。
- 活动模板变化时重新核价。
- 一次只改一个主要病因。
- 未达标时不盲目加码同一动作。

## 人工审批

调价、降低利润线、暂停广告、改变预算和报活动必须经过人工确认。工具可以生成建议和操作清单，不直接执行资金相关动作。
