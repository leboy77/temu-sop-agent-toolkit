# 06 - Fulfillment

## 定位

管理从平台订单到 ERP、仓库、面单、发货和轨迹的确定性流程。

## 输入

- 已发布商品和目标仓库
- 订单数据
- ERP/物流授权
- 配送模板和渠道
- 库存快照

## 输出

- 推单记录
- 面单记录
- 运单号与轨迹
- 库存变化
- 异常单及处理结果

## 执行规则

1. 订单推送和面单推送分开确认。
2. 推送前检查国家、仓库、渠道和配送模板。
3. 欧洲按国家分批，不混合渠道。
4. 美国按东部、中部、西部仓库匹配模板。
5. 接口超时先查询状态，避免重复推单。
6. 发货后核对轨迹和库存，关闭异常。

## 关键指标

- 按时推送率
- 面单成功率
- 超时未发货数
- 地址/渠道异常数
- 库存差异
- 物流轨迹缺失数
