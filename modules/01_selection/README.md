# 01 - Selection

## 定位

把候选商品整理成可判断的比较集，辅助业务负责人做选品决定。Agent 不代替最终决策。

详细的市场问卷、指标计算和 Prompt 位于
[`agents/01_market_research`](../../agents/01_market_research/README.md)。

## 输入

- 来源链接或类目导出
- 目标市场与业务模式
- 商品标题、价格、销量或评论
- 款式、材质、颜色和 SKU 数量
- 供应商报价、重量和履约能力

## 输出

- 去重后的候选商品表
- 款式和配置聚类
- 重复款、失效链接和缺图清单
- 风险项与待确认项
- 建议进入核价测试的商品

## 判断维度

| 维度 | 关注点 |
| --- | --- |
| 需求 | 销量、评论增速、收藏或加购信号 |
| 竞争 | 同款密度、价格带、头部集中度 |
| 供应 | 是否可做、起订量、交期、补货 |
| 履约 | 重量、体积、退货和包装风险 |
| 素材 | 图片质量、图案授权、可重制程度 |
| 业务 | 是否符合 POD/普通商品模式 |

## 门控

- 来源与采集时间必须记录。
- 竞品数据不得直接作为己方参数。
- 未解决版权或品牌授权时不得进入素材生产。
- 业务负责人确认后才能进入 `PRICED`。
