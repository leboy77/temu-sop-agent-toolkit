# 08 - Aftersales

## 定位

把退款、差评、咨询和物流问题转换为可修复的商品信息，而不是只做一次性客服回复。

## 输入

- 已脱敏评论和工单
- 商品卡与规格表
- 图片和详情页
- 物流与订单状态
- 客诉处理政策

## 分类

| 类型 | 处理 |
| --- | --- |
| 描述误解 | 修改标题、图片、尺码说明或注意事项 |
| 参数不符 | 先核实商品，再修正所有内容来源 |
| 尺码问题 | 核对尺码表、测量方式和图片 |
| 质量缺陷 | 供应商和批次分析，不靠文案掩盖 |
| 物流问题 | 履约异常流程 |
| 包装缺失 | 补包装清单图或改进包装 |
| 恶意或异常投诉 | 人工按平台流程处理 |

## 输出

- 问题分布
- 可修复项和不可修复项
- 回流到商品卡的修改建议
- 客服话术草案
- 复测指标

## 红线

- 不以退款诱导删除差评。
- 不组织虚假评价或举报。
- 不编造参数、批次或物流原因。
- 不把产品质量问题全部解释为买家误解。
