# 05 - Compliance

## 定位

根据目标市场、类目和业务模式生成发布前合规检查包。规则必须可追溯，Agent 不能自行创造法规结论。

## 输入

- 市场配置
- 商品类目和材质
- 制造商、欧代、税务和包装资料
- 标签、包装和说明书
- 商品参数、图片和文案
- 平台当前合规通知

## 输出

- 合规清单
- 缺失项与不一致项
- 需要人工审批的高风险项
- 可发布或阻断结论

## 通用红线

- 不伪造认证、测试报告、销量、评价或品牌授权。
- 不虚标参数、材质、功效、产地或安全能力。
- 不使用未授权商标。
- 图片不暗示产品具备未经验证的功能。
- 材料地址、税务地址、标签主体和后台信息必须一致。

## 欧洲附加项

- VAT、欧代、制造商、商品识别码、包装 EPR、标签。
- 全托管/半托管模式下仍需核对平台和经营者责任。

## 美国附加项

- 制造商信息、商品标签、材质和尺码准确性。
- POD 图案版权、商标和人物肖像权。
- 售后和责任声明不得超出实际能力。

## 门控

只有合规负责人明确批准，商品才能从 `ASSETS_READY` 进入 `COMPLIANCE_READY`。
