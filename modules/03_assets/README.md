# 03 - Assets

## 定位

把商品事实转换为可发布、可追溯的图片、标题和卖点素材包。

## 输入

- 已批准的 `product_brief.json`
- 已通过的核价表
- 供图和图案授权
- 尺寸表和 SKU 映射
- 市场语言和视觉要求

## 输出

- 商品主图
- SKC 颜色图
- 详情图或场景图
- 标题候选
- 核心卖点与副卖点
- 图片授权和生成记录

## 生产原则

1. 商品轮廓、结构和材质必须与实物一致。
2. 印花区域只覆盖可生产区域。
3. 图片内参数只引用最终规格表。
4. 不使用未授权品牌、认证标志、他人评价或销量截图。
5. AI 生成图保留提示词、来源、版本和人工验收记录。

## 文案约束

- 目标市场母语直接生成。
- 数字必须有来源。
- 不使用绝对化、无法证明或平台禁止的表述。
- SKU 标题不得加入颜色词，除非市场配置明确允许。

## 门控

- 每个 SKU 有足够的图片；
- 图片与 SKU、颜色、尺码对应；
- 素材授权完整；
- 参数和标题通过规则检查。
