# 02 - Pricing and SKU

## 定位

把成本、物流、费用、退货和利润目标转换成可复核的价格与 SKU 结构。

## 输入

- `templates/price_sheet.csv`
- 市场配置中的税率、运费和费用规则
- 实际采购价、重量、尺寸和包装
- 成本币种、销售币种和汇率
- 风格退货率
- 目标毛利和战略亏损上限

## 输出

- 单件总成本
- 盈亏价
- 目标售价
- 活动价和流量加速价底线
- 每个 SKU 的利润和利润率
- 不通过项与审批记录

## 计算

运行：

```powershell
python scripts/calc_price.py templates/price_sheet.csv
```

脚本只做确定性计算。价格决策、促销节奏和亏损换取销量的策略由业务负责人审批。

价格表必须明确 `cost_currency`、`sale_currency` 和 `fx_sale_to_cost`。脚本同时在成本币种与销售币种中输出盈亏价，避免人民币成本和美元售价混算。

## SKU 结构

- 引流 SKU 可以低毛利，但不得低于盈亏价，除非有退出条件。
- 主推 SKU 应承担主要成交和利润。
- 高配 SKU 提升客单价，但避免与主推款互相蚕食。
- 套装 SKU 必须有真实组合和库存能力。

## 门控

- 任何必填成本为空，状态保持 `DRAFT`。
- 活动价或券后价低于底线，状态为 `BLOCKED`。
- 价格变化后必须重新校验活动模板和广告目标。
