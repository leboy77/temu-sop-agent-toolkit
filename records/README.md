# Records

运行记录放在本目录或私有存储，默认不提交到 Git。

建议命名：

```text
<product_brief_id>/
├── preflight-<state>-<timestamp>.json
├── assets-manifest.csv
├── listing-pack.md
├── compliance-pack.md
├── exception-log.csv
└── performance.csv
```

记录中的真实账号、地址、联系人、订单和客户信息必须脱敏或存入私有系统。
