# Temu Market Capture

Chrome MV3 插件原型，用于从当前已打开、用户有权访问的 Temu 类目页中采集可见商品信息。

## 安装

1. 打开 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载未打包的扩展程序”。
4. 选择本目录。

## 使用

1. 启动 `python webapp/server.py`。
2. 打开 Temu 类目列表页。
3. 点击插件图标。
4. 选择市场和销量窗口。
5. 点击“采集当前页面”。
6. 确认识别数量后，点击“发送到本地分析台”，或下载带 UTF-8 BOM 的 CSV。

## 重要限制

- 页面中的 `sold / 已售` 通常是累计销量，不等于近 30 天销量。
- 销量窗口不确定时只能下载 JSON，不能进入集中度和价格分析。
- 插件只采集当前页面已经加载出来的商品；需要更多样本时，先手动滚动页面再采集。
- 公开列表卡通常不提供卖家、评分和真实上架天数，缺失字段不会自动补造。
- Temu 页面 DOM 可能频繁变化。如果自动识别不到卡片，请在插件中填写商品卡片的 CSS 选择器。
- 插件不读取 Cookie、Token 或账号资料，不调用隐藏 API，不绕过登录、验证码或风控。
- 只采集当前页面已显示的公开商品信息。
