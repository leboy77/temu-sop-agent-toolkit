# 欧洲 Y2：白色摇粒绒休闲裤

## 案例目标

验证欧洲 Y2 商品在不牺牲 VAT、欧代、制造商、包装和尺码准确性的前提下进入上架准备。

## 输入

- 市场：欧洲 Y2
- 商品：白色宽松摇粒绒休闲裤
- 可见结构：松紧腰、抽绳、宽腿、毛绒表面
- 现有商品图：3 张
- 当前状态：草稿

## 已完成的准备

1. 建立商品卡、代价表草稿和合规包草稿。
2. 将图片登记为私有素材，公开仓库不包含图片。
3. 把 VAT、欧代、制造商、商品识别码、EPR、标签和尺码列为阻断项。
4. 不在材质、保暖和洗护信息未确认时编写功能属性。

## 当前阻断

- 供应商、采购价和重量缺失。
- 没有真实尺码表和库存。
- 材质成分和洗护说明缺失。
- 图片与设计授权待确认。
- 欧洲主体和合规资料尚未建立。

## 检查器结论

状态为 `BLOCKED`，下一步回到 `02_pricing`。补齐成本和规格后，再进入素材与合规流程。
