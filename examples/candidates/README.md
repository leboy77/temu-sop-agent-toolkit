# Pilot Product Candidates

这里是从现有内部资料和本地商品素材中筛选出的试点候选。实际图片保存在本地私有目录，不进入公开仓库；公开仓库只保留脱敏后的商品特征、风险和待补字段。

所有图片目前统一标记为：

- `rights_status: pending_confirmation`
- `publish_allowed: false`

图片可以用于内部方案和样稿，不能直接当作正式上架素材。

## 当前缺失

三个候选都还缺：

- 供应商和采购价
- 重量与包装尺寸
- 材质成分和洗护说明
- 可用尺码和库存
- 目标售价
- 图片与图案授权确认
- 平台类目和合规资料

这些字段不能靠视觉推测补齐。
