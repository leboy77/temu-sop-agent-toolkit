# Automations

自动化只负责确定性执行，不负责最终商业判断。

## 已有工具映射

| 工具 | 对应模块 | 必需输入 | 必需输出 |
| --- | --- | --- | --- |
| Temu 核价助手 | 02 Pricing | 价格表、站点、SKU | 价格结果、跳过原因 |
| 自动复色助手 | 03 Assets / 04 Listing | 商品卡、SKC/SPU、图片计划 | 成功、失败、待确认记录 |
| 下架归档助手 | 08 Aftersales | SPU 清单、归档目录 | 下架结果、图片归档 |
| 广告花费监控 | 07 Growth | 广告页面、阈值、时间窗 | 当前花费、告警和快照 |

这些工具的现有项目位于个人 `chatgpt-projects` 仓库的 `temu-operations` 分类下。

## 接入要求

1. 输入必须是固定格式，不能依赖人工临时解释。
2. 运行前检查商品卡、价格和合规状态。
3. 每个批次记录 `run_id` 和 `product_brief_id`。
4. 提交按钮和资金相关动作必须有人工确认。
5. “未知状态”先查询，不允许直接重复提交。
6. 工具选择器或平台页面变化时，先停用并升级版本。

## 推荐执行顺序

```text
价格计算脚本
  -> 商品卡完整性检查
  -> 图片与合规检查
  -> 批量模板检查
  -> 人工批准
  -> 浏览器自动化
  -> 平台结果查询
  -> 异常记录
```
