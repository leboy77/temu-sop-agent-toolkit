## 实际计算链

```text
当前运费成本 = 克重 × 当前每公斤运费 + 当前操作费
当前基础成本 = 当前运费成本 + 采购价
含售后成本 = 当前基础成本 × (1 + 售后率)

申报价 = 售价 ÷ 0.9
发品价 = 申报价 × 1.8
流量加速价 = 售价 × 1.1

正常利润 = 售价 + 运补 - 含售后成本
最低价利润 = 最低售价 + 运补 - 含售后成本

新物流成本 = 克重 × 新每公斤运费 + 新操作费
新物流含售后成本 = (新物流成本 + 采购价) × (1 + 售后率)
新物流利润 = 售价 + 运补 - 新物流含售后成本
```

## 发现的结构问题

1. 同时存在 34、35、37 列三种布局，不能按固定列字母读取。
2. 有的商品只有“售价”，有的同时有“售价”和“最低售价”。
3. 35 列版本里的利润列按最低售价计算，37 列版本同时展示正常利润和最低价利润。
4. 售价和最低售价按国家不同，不能使用一个全欧统一价格。
5. 德国的第一组重量分档使用了不同于其他国家的新操作费。
6. 部分国家的新物流字段为空，表示只保留当前方案，不应自动当成 0。
7. 有些商品的实际重量超出国家现有重量区间，必须报 `NO_WEIGHT_BAND`。
8. 表格包含物流渠道、追踪号样式和内部费率，只适合作为私有配置。

## 已实施的防错

- 按字段名归一化，不依赖固定列号。
- 同一国家有重叠重量区间时，选择覆盖范围最窄的匹配区间。
- 售价和最低售价分开计算。
- 缺少新物流操作费时标记 `NEW_LOGISTICS_NOT_CALCULATED`。
- 原表公式与脚本计算结果已用德国示例交叉校验。
- 对 ZSK 工作裤的 23 个可匹配国家/重量区间，当前成本、含售后成本、发品价、流量加速价、申报价、最低价利润、最低价投产比和新物流利润共 9 组字段全部与原表一致。
