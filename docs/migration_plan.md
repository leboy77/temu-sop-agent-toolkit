# Migration Plan

## Phase 0 - 私有资料整理

- 保留原始 PDF 在私有目录。
- 对截图中的账号、地址、联系人和真实 SKU 脱敏。
- 把每个流程拆成“目标、输入、动作、输出、异常、负责人”。
- 明确当前规则版本和复核人。

## Phase 1 - 通用基础

- 启用商品生命周期状态机。
- 启用商品卡、核价表、合规包和异常日志。
- 统一市场、仓库、税率和工具配置。
- 欧洲和美国各跑一个脱敏商品。

验收指标：

- 100% 上架试点商品有商品卡和核价表；
- 0 个未审批价格进入发布；
- 0 个合规资料不完整的商品进入批量提交；
- 发布结果 100% 回列表确认；
- 每个异常都有类型、负责人和结果。

## Phase 2 - Agent 与模板

- 建立标题、图片、合规预审和广告诊断 Prompt。
- 为每个 Prompt 配置固定输入和输出。
- 建立 10 个商品的人工基准输出。
- 人工对比 Agent 输出，记录错误类型和修正原因。

## Phase 3 - 工具接入

- 核价工具读取统一价格表。
- 自动复色读取商品卡和图片计划。
- 下架归档写入运行记录。
- 广告监控输出标准化指标。
- 所有工具增加暂停、幂等和结果查询。

## Phase 4 - 闭环

- 记录发布前后指标。
- 活动/广告/售后诊断只改症状指向的环节。
- 复测未通过时重新诊断，不重复加码。
- 每月审查平台规则、价格阈值和工具选择器。

## 必须先解决的数据

- 每个市场当前有效仓库、配送模板和时效；
- 平台费、税费、物流费和退货损耗口径；
- 合规材料负责人和复核周期；
- 每个现有工具的输入输出格式；
- 当前失败类型的频率和人工处理时长。
